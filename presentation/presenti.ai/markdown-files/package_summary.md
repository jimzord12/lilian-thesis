## Troubleshooting Quick Reference

### Issue: Output Exceeds 15,000 Words

**From Quick-Start Guide**:
```
"The word count is [X] words. Please trim:
1. Literature Review: Cut to 1,700 words
2. Discussion: Cut to 2,700 words
Maintain Results section unchanged. Recount."
```

**Time to fix**: 3-5 minutes (AI re-runs)

---

### Issue: Missing Key Metrics in Results

**From Quick-Start Guide**:
```
"Results section needs specific metrics for each finding:
- Exact percentage or mean value
- Statistical significance (p-value)
- Sample size

For example: '78% (n=331/425) improved (p < 0.001)'

Please revise Results section to include these metrics."
```

**Time to fix**: 3-5 minutes (AI re-runs)

---

### Issue: Structure Unclear

**From Quick-Start Guide**:
```
"Please reorganize so there are exactly 15 H2 headings (##) with no H3 (###).
Each H2 should represent approximately one slide topic.

Needed structure:
- 1 H1 title
- 6 main sections (H1)
- 15 H2 topics (##)

Please revise heading hierarchy."
```

**Time to fix**: 2-3 minutes (AI re-runs)
