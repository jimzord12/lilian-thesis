## 🔥 CORE RULES (NON-NEGOTIABLE)

### FORMAT
- ✅ Markdown (.md file format)
- ✅ ONLY bullet points (no paragraphs)
- ✅ Each bullet: 15-25 words max
- ✅ 3-5 bullets per section max

### STRUCTURE
- ✅ # = Title only (use once)
- ✅ ## = Section topics (~15 total = ~15 slides)
- ✅ No ### unless absolutely necessary

### CONTENT
- ✅ Keep: Research questions, methodology, findings with metrics, discussion, conclusions
- ✅ Remove: Appendices, secondary examples, extensive background

### RESULTS (PRIORITY)
- ✅ One ## heading per major finding (5-6 findings)
- ✅ Each finding must include: specific metric (%, mean, p-value)
- ✅ Example: "78% (n=331/425) showed improvement (p < 0.001)"

### VISUALS
- ✅ Include descriptions in brackets
- ✅ Example: "Include bar chart comparing baseline vs. post-intervention"
- ✅ NO actual images or tables

## 🐛 TROUBLESHOOTING QUICK FIX

### Problem: Output exceeds 15,000 words

**Quick fix**: Ask AI:
```
"This is [X] words. Please trim:
- Literature Review: reduce to 1,700 words
- Discussion: reduce to 2,700 words
Keep Results unchanged.
Recount and resubmit."
```

**Fix time**: 3-5 minutes

### Problem: Missing specific metrics in results

**Quick fix**: Ask AI:
```
"Results section needs specific metrics.
Add for each finding:
- Exact percentage or mean
- Statistical significance (p-value)
- Sample size

Example: '78% (n=331/425) improved (p < 0.001)'

Revise Results section."
```

**Fix time**: 3-5 minutes

### Problem: Structure unclear / wrong number of slides

**Quick fix**: Ask AI:
```
"Please organize so exactly 15 H2 headings (##).
No H3 (###).
Each ## becomes one slide.
Current structure needs: [describe needed changes]"
```

**Fix time**: 2-3 minutes
